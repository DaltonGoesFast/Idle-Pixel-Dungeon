# Balance

All numbers live in `data/*.json`; the tables below are generated by `python3 tools/gen_docs.py`.

## Core math (deterministic, no RNG in combat)

- **Collapsing SPD ranges:** SPD rolls `NormalIntRange(min, max)`; we use `floor((min + max) / 2)`.
  - Weapons: SPD `min = tier`, `max = 5 * (tier + 1)` -> Worn Shortsword (t1) 1-10 -> **5**.
  - Armor: SPD `DRMax = 2 * tier` -> Cloth (t1) 0-2 -> **1** flat DR.
  - Strength requirement: SPD `8 + 2 * tier` (t1 10, t2 12, t3 14).
- **Physical damage taken** = `max(0, dmg - DR)`. Then Barrier absorbs first, then HP.
- **Chip rule:** a hit fully blocked by DR still removes 1 Barrier.
- **Barrier** = class base + heirloom (Broken Seal +3) + armor barrier (= tier) + armor upgrades. Refreshes to 100% at the start of every fight (unless the torch is out: darkness = 0 Barrier).
- **Surprise attack** (hero attacks while standing on a door or tall grass): `dmg * 1.5` (Dagger x2), ignores DR, knocks the target back 1 tile. Knockback into a wall/unit = 1 dmg; into a chasm = instant kill (loot halved, recovered when you descend).
- **Strength shortfall:** each point below a weapon's Str requirement = -2 damage; below armor's = -1 DR.
- **Upgrades:** weapon `+floor((tier+1)/2)` dmg per level; armor +1 DR and +1 Barrier per level; capped by Blacksmith level.
- **Turn clock:** SPD-style. Each actor has a `next` time; hero wins ties. Normal = 1.0, fast (crab) = 0.5, heavy weapon (mace) = 1.5 ticks.
- **Levels:** SPD `maxExp = 5 + 5 * level`; +5 HT per level (SPD).
- **Telegraphs:** Gnoll Scout throws (dmg + 2) at your tile from range 2-3, resolving 1 tick later. Goo pumps up every 3rd action: all 8 surrounding tiles take `dmg * 3` one tick later. Don't fight it in a corner.
- **Rogue Cloak:** 2 charges/fight; 1 tick to activate, hidden for 2 more ticks: enemies stop chasing/attacking/throwing; the next attack is a Surprise (dagger x2) and breaks the cloak.
- **Huntress Spirit Bow:** unlimited arrows, line of sight within 6, dmg = floor(avg of SPD (1 + lvl/5)-(6 + lvl/2.5)), DR applies, Surprise from cover. Studded Gloves melee: 3 dmg at 0.5 ticks.
- **Mage staff bolt:** 2 charges, +1 per 4 ticks, ignores DR.

## Delve
- Torch drains 0.4 per 1% of floor progress (a full Sewers run = 200 torch = the starting 100 + 2 torches), satiety 0.4. A torch / ration is auto-used under 20 (restores 60 / 70).
- Torch at 0 = **darkness**: fights start with 0 Barrier. Satiety at 0 = -1 HP per 5% (never below 1).
- Passive gathering: +1 gold every 4%, +1 dew every 12%.
- 4 events per floor at ~22/45/68/90% (+-2, seeded). Event 1 is always a fight; the rest roll combat 5 : door 2 : special 2. Floor 5's last event is Goo.
- Descending heals 20% of max HP. Potions of Strength at fixed milestones: floor 2 @ 50% and floor 4 @ 50%.

## Why the crab changed (v0.2.0)
SPD's crab (dmg 1-7 -> 4, DR 0-4 -> 2, speed x2) dealt ~6 damage per tick to a 20 HP Warrior while needing 5 hits to kill. In SPD the hero's evasion and the crab's misses make that survivable; with 100% accuracy it was not. Crab is now dmg 2 / DR 1 (still double speed, so it strips Barrier fast - the GDD "swarm" role). Goo went HT 100 -> 50 and DR 0-2 -> 0 for a similar reason (low-damage classes needed 25+ hits).

## Verification
`tests/run_tests.gd` plays every encounter set in every room with `CombatBot` (sensible tactics, no hindsight): the starting Warrior must win all of them, the Mage >= 90%, and a Lv3/Lv4 Warrior with 2 potions must beat Goo. `[fullrun]` additionally plays 10 seeded full expeditions per class (2 rations, 2 torches, 2 potions); each class must clear >= 5/10. Results at v0.3.0: Warrior 10/10, Mage 7/10, Rogue 7/10, Huntress 8/10 (deaths are mostly at Goo).
